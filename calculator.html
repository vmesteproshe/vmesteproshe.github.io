Калькулятор для пары

Два простых расчёта: как делить общие расходы и сколько месяцев понадобится, чтобы собрать финансовую подушку. Всё считается прямо в браузере — данные никуда не отправляются.

Совместный бюджет · Финансовая подушка · Без регистрации

01 · Совместный бюджет

Совместный бюджет

Сумма, которую пара тратит вместе каждый месяц.

Результат

  • Доля первого партнёра 0 %
  • Доля второго партнёра 0 %
  • Взнос первого в общий бюджет 0 ₽
  • Взнос второго в общий бюджет 0 ₽
  • Личные деньги первого партнёра 0 ₽
  • Личные деньги второго партнёра 0 ₽

Введите доходы и расходы — результат появится здесь сразу.

02 · Финансовая подушка

Финансовая подушка

Аренда, еда, транспорт, кредиты — без чего пара не сможет обойтись.

Срок запаса

Результат

  • Цель накоплений 0 ₽
  • Срок достижения 0 месяцев

Цель = обязательные траты × выбранный срок. Срок округлён в большую сторону.
